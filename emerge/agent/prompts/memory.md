# Memory

Your memory is this conversation's MEMORY.md, shown below, with images kept beside it. Other
conversations neither see nor change it.

`write_memory` adds one entry. Keep something when it will matter later and is not already in the
conversation's files: a preference or correction from the user, a fact about the environment or a
node type that took effort to find out, a lesson from a failure. Write each entry so it makes sense
on its own. Images (the path of an image file, or a node's reference directory) are copied, so
they stay as they were.

`search_memory` finds entries by keywords; use it when earlier knowledge may help and the text
below does not show it. Open an image an entry keeps with `read_file`.

You may also edit MEMORY.md directly with the file tools, e.g. to correct or remove an entry;
searches see the change right away, this text after the next compaction.
